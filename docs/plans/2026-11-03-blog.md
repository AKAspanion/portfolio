# Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: the project's workflow policy names the executor (`run.executor`): ga:implement-with-subagents by default, or ga:implement. Follow the policy and this plan's Checkpoints. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A personal blog on spanion.in: public `/blog` list and `/blog/:slug` post pages, and an owner-only manager at `/blog/manage` with a TipTap editor, backed by Firestore and Firebase Storage, with every SEO feature: per-page tags, structured data and the article in the HTML crawlers receive, real 404s, a generated sitemap and an RSS feed.

**Architecture:** The site stays a static Vue 3 SPA on Firebase Hosting. Blog routes are lazy-loaded and alone import Firebase and TipTap. Posts are Firestore documents whose body is TipTap JSON, rendered to HTML through a fixed schema with a protocol allowlist. Firestore and Storage security rules in the repo are the only write boundary, and they admit one verified Google account. A 2nd-gen Cloud Function, `seo`, sits behind Hosting rewrites for `/blog`, `/blog/**` and `/sitemap.xml`: it fills the live `index.html` with each page's head, article and data, using the same post helpers as the browser, bundled by esbuild.

**Tech Stack:** Vue 3, Vite, Vuetify, Pinia, Vue Router, vue-i18n, TypeScript (`package.json`); Firebase JS SDK (`firebase`; `firebase/firestore/lite` for public reads); TipTap 3 (`@tiptap/vue-3`, `@tiptap/starter-kit`, `@tiptap/extension-image`, `@tiptap/extension-youtube`, `@tiptap/extension-code-block-lowlight`, `@tiptap/html`, `@tiptap/pm`, `lowlight`); Vitest + jsdom; Playwright with axe; `@firebase/rules-unit-testing` on the Firebase emulators through `firebase-tools@15.34.2`; Cloud Functions for Firebase (`firebase-functions`, `firebase-admin`, Node 22, `asia-south1`) built with `esbuild`; GitHub Actions (`.github/workflows/ci.yml`, `.github/workflows/deploy.yml`).

**Spec:** [docs/specs/2026-11-03-blog.md](../specs/2026-11-03-blog.md)

## Global Constraints

- Firebase, TipTap and lowlight are imported only from blog route chunks (`BlogList.vue`, `BlogPost.vue`, `BlogManage.vue`, `BlogEditor.vue` and what they import). Nothing reachable from `src/main.ts`, `src/App.vue`, `HomeView.vue` or `NavMenu.vue` imports them, statically or through `src/posts.ts`.
- The owner is the account signed in with the `google.com` provider whose token carries `email == 'panditankit1995@gmail.com'` and `email_verified == true`.
- Every visible string is an i18n key present in both `src/assets/i18n/en/lang.json` and `src/assets/i18n/hi/lang.json` (Hindi is a translation of the English copy given here).
- The rendered post HTML is the only `v-html` in the blog, and it comes only from `renderPost()`.
- `MAX_IMAGE_MB = 10`. Images are resized to at most `2000` px wide and encoded as WebP before upload.
- Each failure is logged once with `console.error` and its error code only, never post content.
- Components and views use `<style scoped>` only; shared styles go in `src/styles/main.css` (`knowledge/decisions/scoped-component-styles.md`).
- The site's address is `SITE_URL = 'https://spanion.in'` in `src/util/seo.ts`; every absolute URL in tags, JSON-LD, the sitemap and the feed is built from it.
- The function reads Firestore with admin rights, which bypass the security rules: every query it makes carries `status == 'published'`.
- Commit messages are plain sentences.

**Acceptance:**

- Given every `VITE_FIREBASE_*` set, `blogConfigured()` is true; given any one empty, it is false and `firebaseApp()` throws `blog-not-configured`.
- `listPublished()` queries `posts` with `status == 'published'`, `orderBy('publishedAt', 'desc')` and `limit(10)`, and returns `cursor: null` when fewer than 10 come back.
- `listPublished({ tag: 'travel' })` adds `where('tags', 'array-contains', 'travel')`; `listPublished({ after })` adds `startAfter(after)`.
- `getPublishedBySlug('hello-world')` queries `status == 'published'` and `slug == 'hello-world'` with `limit(1)` and returns `null` when nothing matches.
- `toPost` turns `createdAt`, `updatedAt` and `publishedAt` into `Date`s and keeps `publishedAt: null`.
- `renderPost` renders a paragraph, H2, H3, bold, italic, strike, inline code, a link, both list kinds, a quote, a code block with a language class, a figure with alt and caption, a horizontal rule and a YouTube embed.
- A link mark with `javascript:alert(1)` or `data:text/html,…` renders as plain text with no `<a>`.
- An `https://example.com` link renders with `target="_blank"` and `rel="noopener noreferrer"`.
- A figure whose `src` is `http://…` or `data:…` is dropped from the output.
- A YouTube node whose `src` is `https://evil.example/embed/x` is dropped; `https://youtu.be/dQw4w9WgXcQ` renders an iframe at `https://www.youtube-nocookie.com/embed/dQw4w9WgXcQ`.
- A text node containing `<script>alert(1)</script>` is escaped, not executed.
- `slugify('Hello, World!', 'abc123xyz')` is `hello-world`; `slugify('Café Déjà vu', …)` is `cafe-deja-vu`; `slugify('नमस्ते दुनिया', 'abc123xyz')` is `post-abc123`; a 150-character title gives a slug of at most 100 characters with no trailing hyphen; `slugify('Manage', 'abc123xyz')` is not `manage`.
- `isValidSlug` rejects `manage`, `Hello`, `a--b`, `-a`, `a-`, and a 101-character slug; accepts `my-trip-2026`.
- `readingMinutes` of an empty doc is `1`; of 401 words is `3`; counts text inside lists, quotes and code blocks.
- Every new key in `en/lang.json` exists in `hi/lang.json` (the existing `content.spec.ts` parity test passes).
- The privacy policy, in both languages: `privacy.sections.stored.body` says visitors have no accounts and the only sign-in is the blog manager's, used by the site owner alone; it names what Firebase keeps in a visitor's browser on blog pages, found by reading the installed `firebase` package (for example the `firebase-heartbeat-database` IndexedDB database), or says it keeps nothing if that is what the package does for `firebase/firestore/lite` reads. `privacy.sections.ads.body` says the home page and the blog show ads. `privacy.sections.hosting.body` adds that blog posts and images are served from Cloud Firestore, Cloud Storage for Firebase and Cloud Functions for Firebase, which may log each request, including the IP address. `UPDATED` in `PrivacyPolicy.vue` is the day the task is built.
- `npm test` doesn't pick up `rules/**`, and `npm run type-check` covers `vitest.rules.config.ts`, `rules/**` and `functions/src/**`.
- `index.html` (read from disk in `indexHtml.spec.ts`) has exactly one `<!-- seo:start -->` before exactly one `<!-- seo:end -->`, and between them the `<title>`, the meta description, the canonical link, every `og:` and `twitter:` tag and the JSON-LD script; nothing of those outside them.
- `pageTitle({ title: 'Goa', seoTitle: '' })` is `Goa — Ankit Kumar Pandit`; with `seoTitle: 'Goa in 3 days'` it is `Goa in 3 days — Ankit Kumar Pandit`.
- `pageDescription` returns `seoDescription` when set; otherwise a 300-character excerpt is cut at the last space at or before 159 characters and ends with `…`; a 120-character excerpt is unchanged.
- `postHead` for a post with a cover has canonical `https://spanion.in/blog/<slug>`, `og:type article`, `og:image` the cover URL with `og:image:width`, `og:image:height` and `og:image:alt`, `og:locale` `en_IN` (or `hi_IN` for `lang: 'hi'`), `article:published_time` and `article:modified_time` as ISO strings, one `article:tag` per tag, and `twitter:card` `summary_large_image`; without a cover, `og:image` is `https://spanion.in/images/logo/logo-512x512.webp` at 512 × 512 and `twitter:card` is `summary`.
- `listHead({})` has title `Blog — Ankit Kumar Pandit`, canonical `https://spanion.in/blog` and `robots: null`; `listHead({ tag: 'travel' })` has the same canonical and `robots: 'noindex, follow'`.
- `postJsonLd` gives a `BlogPosting` with `headline`, `description`, `image`, `datePublished`, `dateModified`, `inLanguage`, `keywords` (the tags), `mainEntityOfPage` (the canonical URL), and `author` and `publisher` a `Person` named Ankit Kumar Pandit at `https://spanion.in/`; and a `BreadcrumbList` of Home (`https://spanion.in/`), Blog (`https://spanion.in/blog`) and the post.

- `fromEmbedded(toEmbedded(post))` equals `post`; `fromEmbedded` returns `null` for `null`, a string, or an object missing `slug` or with a non-ISO `updatedAt`.
- A cover or figure `src` that isn't `https:` never reaches `og:image` or JSON-LD `image`: the default image is used instead.
